# MT_TOOLS — أدوات صيانة الشبكات

Native Android ICMP monitoring app, inspired by Termux ping output. Foreground background monitor, per-packet history, outage timer, local CSV log and Android notification.

**Android:** 8.0+ · **Target:** Android 15 · **Build:** GitHub Actions `Android APK` produces `MT_TOOLS.apk` in GitHub Releases and workflow artifacts.

See the [build workflow](.github/workflows/android.yml). The APK is sideloaded outside Google Play.
Without permanent signing secrets, the workflow produces a debug-signed APK that cannot update a differently-signed installation.

## الإصدار 5.1.0

- بمجرد تأكيد الانقطاع بعد فقد نبضتين متتاليتين، ينشئ التطبيق **إشعاراً مستقلاً ذا رقم جديد لكل حالة**، ongoing chronometer يعد من لحظة الفقد الأولى دون اعتماد على فتح التطبيق.
- عند التعافي يتبدل **الإشعار ذاته (نفس ID)** إلى نتيجة «عاد الاتصال» بمدة الفصل الفعلية، ويصبح قابلاً للإزالة ولا يمسّ إشعارات التعافي السابقة.
- أي فصل لاحق لأي هدف يولد إشعاراً جديداً ويترك إشعارات العودة المكتملة في لوحة الهاتف.
- عند إيقاف المراقبة أو حدوث خطأ فحص، تُنهى حالة الفصل النشطة بنتيجة الإيقاف دون تسجيل عودة اتصال كاذبة.
- كرت RTT كبير لكن بسطر واحد مع `ms` اللاتينية، مثل `104.40 ms` دون التفاف النص.
- اختبار مصادقة العناوين المتزامنة ومنع تكرار المضيف بين الحقول.

### إعداد توقيع APK ثابت للتحديث فوق الإصدارات السابقة

النسخ القديمة كانت بتوقيع debug مؤقت؛ مفتاح التوقيع السابق لم يُحفَظ، ولذلك قد تحتاج **مرة أخيرة** لإزالة النسخة القديمة عند الانتقال إلى النسخة ذات التوقيع الدائم.
بعد إنشاء المفتاح الآمن وحفظه في GitHub Actions Secrets سيصبح مفتاح جميع النسخ القادمة واحداً، ويمكن تحديث التطبيق من دون حذف الإصدار السابق.
لا تضع ملف keystore أو كلمة مروره في المستودع العام.

1. نفّذ محلياً `bash scripts/setup-stable-signing.sh` على جهاز تثق فيه ولديه Java keytool (يستخدم GitHub CLI إن توفر).
2. احفظ نسخة احتياطية خاصة من `~/.mttools-signing/mttools.jks` وكلمة مروره.
3. تأكد من وجود السرَّين `MT_TOOLS_KEYSTORE_BASE64` و`MT_TOOLS_KEYSTORE_PASSWORD` في GitHub Repository Settings > Secrets and variables > Actions.
4. أعد تشغيل GitHub Actions لبناء APK بالمفتاح الجديد. افحص شهادة APK المنشورة وتحقق من أنها لا تتغير بالإصدارات اللاحقة.

إذا لم تضبط السرَّين، GitHub يبني نسخة Debug جديدة **ولا تُحل مشكلة التثبيت فوق النسخة القديمة**.

## Behavior

- 1 ICMP echo per selected interval (1, 2 or 5 seconds), reporting RTT/timeout/error per pulse.
- Elapsed outage starts at first timed-out echo and ends on first successful echo.
- A foreground `specialUse` monitoring service continues while UI is closed with a persistent notification and partial wake lock.
- CSV files rotate in internal storage. UI can export records using the Android file picker.
- Some manufacturers may terminate foreground services because of aggressive battery optimization. Allow unrestricted battery use for reliable monitoring; Android cannot promise absolute uptime.

## Build

Requires Android SDK 35, Java 17+, Gradle 8.10.2.

